# Brand assets

`cka-logo.png` — the CKA Construction Group mark, shown in the portal header
and on the printed record. Use the transparent PNG (`CKA logo for Corecon II.png`
in SharePoint → 04 Company Branding → Logos & QR → CKA Artwork).

The portal loads it from this folder's raw URL. If it is missing, the header
falls back to the CKA Construction wordmark in type — nothing breaks, the logo
just is not there.

## Verified brand values

Taken from brand assets, not sampled by eye. Do not change these without a
source.

| Value | Where it came from |
|---|---|
| `#668399` | The slate in the company email signatures (`signature-*.htm`) |
| CMYK 40/14/5/38 → `#5F8896` | Print spec for the same slate; agrees with the above |
| CMYK 0/0/0/80 → `#3D3D3D` | The wordmark grey. Neutral — there is no blue in it |

`#4F6B7D` in the portal is `#668399` darkened to pass contrast on light
backgrounds. It is a derived value, not a brand colour.
