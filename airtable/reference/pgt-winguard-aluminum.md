# PGT WinGuard Aluminum — option lists

Taken from the WinGuard Aluminum brochure (PGT, 20pp), pages 13 and 15. Verify against the
current price book before a job is released — brochures lag the order desk.

## Frame colors (4)

| Color | Sampled hex |
|---|---|
| Black | `#303232` |
| Bronze | `#454035` |
| Clear Anodized | `#E7E8EA` |
| White | `#FFFFFF` |

Hex values are sampled from the brochure chips, for the portal's fallback tile only. They are
not a color match — the chip image is what the owner should be deciding from.

## Glass (7 tints)

Clear · Bronze · Gray · Green · Azure Blue · Graylite® II · Solarcool® Bronze

- **High-performance Low-E coatings available** — carried on all of the above, and what the
  energy code is satisfied with.
- **Privacy glass**: Obscure, Rain, White Interlayer — specified per opening.
- **Turtle glass**: tinted to reduce light for marine turtle habitat. Coastal parcels may require it.

## Grid styles (3)

None · Colonial · Brittany / Prairie

Grid construction, which follows from the glass package:

| Glass | Grid |
|---|---|
| Laminated | 1" raised exterior grid with flatbar interior |
| Laminated | 1" flat/flat applied |
| Laminated insulating | 9/16" flat grid between the glass |
| Laminated insulating | 1" Contemporary SDL |
| Laminated insulating | 13/16" Contemporary SDL |

Not all grids are available on both windows and doors.

## Sliding glass door hardware (SGD 770 / 770NS)

| Style | Finishes offered |
|---|---|
| Raised | White, Matte Black, Satin Nickel, Oil-Rubbed Bronze, Bronze |
| Contemporary | White, Matte Black, Satin Nickel |
| Curved | White, Satin Nickel, Bronze |
| Modern | Matte Black, Satin Nickel, Black — **SGD 770NS only** |
| Beveled | White, Matte Black, Satin Nickel, Oil-Rubbed Bronze, Black — **SGD 770NS only** |

Style and finish are not independent. Confirm the combination with the manufacturer before release.
